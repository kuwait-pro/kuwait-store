💻 Code Snippets Manager:
═══════════════════════════════════════════════════════════════

   ✨ مثل إضافة Code Snippets في WordPress تماماً!

   المميزات:
   ✅ محرر أكواد احترافي (CodeMirror)
   ✅ دعم PHP, JavaScript, CSS, HTML
   ✅ تفعيل/تعطيل فوري
   ✅ نظام أولويات (1-100)
   ✅ تصدير/استيراد
   ✅ 8 أمثلة جاهزة

   كيفية الاستخدام:
   1. افتح Code Snippets
   2. اضغط "إضافة كود جديد"
   3. املأ البيانات
   4. اكتب الكود
   5. احفظ!
