# متجر الكويت 🇰🇼

متجر إلكتروني متكامل مبني بتقنية Next.js لعرض وبيع المنتجات في الكويت.

## المميزات ✨

- 🛍️ عرض المنتجات بشكل احترافي
- 🔍 نظام بحث متقدم
- 🛒 سلة تسوق ذكية مع حفظ تلقائي
- 📱 تصميم متجاوب لجميع الأجهزة
- 💬 طلب مباشر عبر واتساب
- 🎨 واجهة عربية بالكامل
- ⚡ أداء عالي مع Static Site Generation
- 🔒 آمن ومحسّن لمحركات البحث (SEO)

## التقنيات المستخدمة 🛠️

- **Next.js 15.3** - إطار عمل React
- **React 19** - مكتبة واجهة المستخدم
- **CSS3** - تنسيق متقدم
- **Context API** - إدارة الحالة
- **GitLab Pages** - الاستضافة

## التثبيت والتشغيل 🚀

### المتطلبات
- Node.js 18 أو أحدث
- npm أو yarn

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd kuwait-store
```

2. **تثبيت الحزم**
```bash
npm install
```

3. **تشغيل المشروع محلياً**
```bash
npm run dev
```

سيعمل المشروع على: `http://localhost:3000`

4. **بناء المشروع للإنتاج**
```bash
npm run build
```

## هيكل المشروع 📁

```
kuwait-store/
├── components/          # المكونات القابلة لإعادة الاستخدام
│   ├── Layout.js       # تخطيط الصفحة الرئيسي
│   ├── ProductCard.js  # بطاقة المنتج
│   └── FloatingButtons.js # أزرار عائمة
├── context/            # إدارة الحالة
│   └── CartContext.js  # سياق السلة
├── data/               # بيانات المنتجات
│   └── kuwait-products.json
├── pages/              # صفحات التطبيق
│   ├── _app.js        # تطبيق رئيسي
│   ├── index.js       # الصفحة الرئيسية
│   ├── cart.js        # صفحة السلة
│   └── product/
│       └── [id].js    # صفحة تفاصيل المنتج
├── public/             # الملفات الثابتة
├── styles/             # ملفات التنسيق
│   └── globals.css
└── next.config.js      # إعدادات Next.js
```

## الإعدادات ⚙️

### تخصيص رقم الواتساب

في الملفات التالية، قم بتغيير رقم الواتساب:
- `components/FloatingButtons.js`
- `components/Layout.js`
- `pages/cart.js`
- `pages/product/[id].js`

ابحث عن: `201110760081` واستبدله برقمك.

### إضافة منتجات جديدة

عدّل ملف `data/kuwait-products.json` وأضف منتجاتك بالصيغة التالية:

```json
{
  "id": "product-id",
  "title": "اسم المنتج",
  "description": "وصف المنتج",
  "category": "الفئة",
  "pricing": {
    "regular": 10.000,
    "sale": 8.000,
    "currency": "د.ك"
  },
  "media": {
    "main_image": "رابط الصورة الرئيسية",
    "gallery": ["صورة1", "صورة2"]
  }
}
```
