# ⚡ تشغيل سريع

## 🚀 أمر واحد لتشغيل كل شيء:

### الطريقة 1: نقرة مزدوجة
```
انقر نقراً مزدوجاً على: START.bat
```

### الطريقة 2: PowerShell
```powershell
.\start.ps1
```

### الطريقة 3: NPM
```bash
npm run start:all
```

---

## 📋 ما سيحدث:

1. ✅ تثبيت الحزم تلقائياً
2. 🏗️ بناء المشروع لجميع المنصات
3. 🔍 تحسين SEO
4. 🎨 فتح لوحة التحكم
5. 🚀 تشغيل السيرفر على http://localhost:3000

---

## 🎛️ الوصول السريع:

### لوحة التحكم الشاملة:
```bash
npm run admin
```

### Code Snippets مباشرة:
```bash
npm run snippets
```

### تشغيل التطوير فقط:
```bash
npm run dev
```
