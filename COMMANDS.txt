🎯 الأوامر الموصى بها:

للمرة الأولى:
  .\BUILD-ALL.ps1          → بناء كل شيء

للتطوير اليومي:
  npm run dev              → تشغيل سريع

للنشر:
  npm run build:all        → بناء جميع المنصات

═══════════════════════════════════════════════════════════════════

📂 المجلدات الناتجة:

بعد البناء ستحصل على:
  ✅ out-github/           → جاهز لـ GitHub Pages
  ✅ out-cloudflare/       → جاهز لـ Cloudflare Pages
  ✅ out-gitlab/           → جاهز لـ GitLab Pages

═══════════════════════════════════════════════════════════════════

⏱️ المدة المتوقعة:

  BUILD-ALL.ps1            → 3-5 دقائق (أول مرة)
  start.ps1                → 3-5 دقائق (أول مرة)
  npm run dev              → 10-30 ثانية

═══════════════════════════════════════════════════════════════════

💡 نصائح:

• استخدم BUILD-ALL.ps1 للبناء الكامل من الصفر
• استخدم start.ps1 للبناء + التشغيل معاً
• استخدم npm run dev للتطوير السريع بدون بناء

═══════════════════════════════════════════════════════════════════

🚀 ابدأ الآن:

نسخ والصق في PowerShell:
  .\BUILD-ALL.ps1

أو انقر نقراً مزدوجاً على:
  BUILD-ALL.bat
