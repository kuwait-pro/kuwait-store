# 🎨 لوحة تحكم متجر الكويت

## 🚀 كيفية الاستخدام:

### 1. **فتح اللوحة:**
```
افتح الملف:
admin/index.html
```
في المتصفح مباشرة!

---

### 2. **إضافة منتج:**
1. اضغط **"+ إضافة منتج جديد"**
2. املأ البيانات:
   - اسم المنتج
   - الوصف
   - الفئة
   - السعر
   - رابط الصورة
3. اضغط **"حفظ المنتج"**

---

### 3. **تعديل منتج:**
1. اضغط **"✏️ تعديل"** بجانب المنتج
2. عدّل البيانات
3. اضغط **"حفظ المنتج"**

---

### 4. **حذف منتج:**
1. اضغط **"🗑️ حذف"** بجانب المنتج
2. أكد الحذف

---

### 5. **حفظ التغييرات:**
1. بعد الإضافة/التعديل/الحذف
2. اضغط **"💾 حفظ التغييرات"**
3. سيتم تحميل ملف `kuwait-products.json`
4. استبدل الملف القديم في:
   ```
   data/kuwait-products.json
   ```

---

### 6. **بناء المشروع:**
```bash
npm run build:cloudflare
wrangler pages deploy out-cloudflare --project-name=kuwait-store
```

---

## 🔄 **هل تنفع لمشاريع أخرى؟**

### **نعم! 100%**

**للاستخدام في مشروع آخر:**

1. انسخ مجلد `admin/`
2. غيّر المسار في السطر:
   ```javascript
   const response = await fetch('../data/kuwait-products.json');
   ```
   إلى مسار ملف JSON الخاص بك

3. افتح `admin/index.html`
